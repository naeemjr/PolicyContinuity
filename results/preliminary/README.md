# Preliminary results (v0.1.0)

**These are not the project's results.** They are the unmodified output of
the first version of PolicyContinuity, kept for provenance.

- Produced by the code at git tag `policycontinuity-preliminary-v0.1.0`.
- One seed, eight adapters, 89 scenarios, hand-labelled expectations, no
  frozen protocol, no held-out data.
- `seed-1/` holds the four files that version wrote. `SHA256SUMS` lists
  their checksums, relative to `seed-1/`.
- `RESULTS-v0.1.0.md` and `LIMITATIONS-v0.1.0.md` are that version's own
  write-up, unedited. Paths and commands inside them refer to v0.1.0.

Why these numbers should not be compared with `results/final/`, and what
changed, is in `docs/PRELIMINARY_VS_FINAL_EVALUATION.md`.
